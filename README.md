# Block Web Element

一个简单实用的 Chrome 扩展：**手动设置生效的网址规则** 和 **想要屏蔽的元素**，打开匹配的网页时自动隐藏这些元素。

## 功能特性

- 🎯 **网址规则匹配**：支持通配符，例如 `*.example.com`、`example.com/*`；不写通配符则按「URL 包含匹配」
- 🧩 **屏蔽元素**：一个输入框同时支持 class / id（`.ad-banner`、`#popup`，必须带前缀）与完整的 CSS 选择器（如 `div[data-ad] > a`）；且**每次只能屏蔽一个元素**
- ⚡ **即时生效**：修改规则后，已打开的页面自动更新
- 🔄 **动态元素处理**：通过 MutationObserver 持续隐藏后加载的匹配元素
- 🏷️ **多规则管理**：一级菜单只显示网址；点击网址进入二级菜单追加屏蔽元素；每条规则可单独启用 / 停用 / 删除
- 🎚️ **抽屉 + 单元素开关**：网址卡片右侧的抽屉按钮可展开该网址下已屏蔽的元素（竖向排列），每个元素都有独立开关；关掉某个元素的开关后，页面上对应的元素会**立即恢复显示**（无需删除规则或重新填写）
- 💾 **配置导出 / 导入**：一键把全部规则导出成 JSON 文件，也可以从 JSON 文件导入配置（按 `id` 合并：已有规则更新、新规则追加，不会删除现有规则）
- 📱 **SPA 兼容**：页面路由变化（如 Vue / React 单页应用）后自动重新应用规则

## 安装方法

### 1. 加载扩展（开发者模式）

1. 打开 Chrome，在地址栏输入 `chrome://extensions/` 并回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点击左上角的 **「加载已解压的扩展程序」**
4. 选择本项目目录（`block-by-class-name`）

### 2. 使用方式

1. 点击浏览器工具栏中的扩展图标（蓝色底白色字母 B 的图标）
2. 点击 **「+ 添加规则」**
3. 填写：
   - **网址规则**：如 `zhihu.com`（包含匹配，所有包含 zhihu.com 的页面都生效）或 `*.example.com/*`（通配符匹配）
   - **屏蔽元素**：如 `.Advert`（class）、`#popup`（id），或完整 CSS 选择器如 `div[data-ad] > a`；class / id 必须带 `.` / `#` 前缀，每次只能填一个元素
4. 点击 **「保存」**
5. 刷新（或直接修改后自动生效）目标页面查看效果
6. 弹窗的**一级菜单只列出网址**；点网址右侧的抽屉按钮（`▸ / ▾ + 数量`）可展开该网址下已屏蔽的元素，每个元素都能单独开关（关闭即恢复显示），也可以点 `✕` 把它从屏蔽列表里移除
7. 点击网址即可进入**二级菜单（编辑界面）**：网址会回填、可以直接修改；元素输入框留空（不会显示已经屏蔽的元素），填好后点「保存」就会把新元素**追加**到该网址下（原有元素保留）；只改网址、不填元素也可以直接保存，点「返回」回到网址列表
8. 点一级菜单底部的 **「导出配置」** 可把全部规则导出为 JSON 文件（文件名带导出时间）
9. 点 **「导入配置」** 选择 JSON 文件即可导入：同 `id` 的规则会被更新，其余追加，结果会提示「导入成功：新增 X 条，更新 Y 条」

## 输入说明

### 网址规则

| 输入示例                    | 匹配方式   | 说明                                                                    |
| --------------------------- | ---------- | ----------------------------------------------------------------------- |
| `example.com`               | 包含匹配   | URL 中包含 `example.com` 即命中（推荐，可同时覆盖 http/https 和子域名） |
| `*.example.com`             | 通配符匹配 | 匹配 `a.example.com`、`b.example.com` 等任意子域名                      |
| `https://www.example.com/*` | 通配符匹配 | 精确匹配整个 URL 前缀                                                   |

### 屏蔽元素

「屏蔽元素」输入框同时支持 class / id 和完整的 CSS 选择器：

| 输入示例                           | 是否允许 | 说明                                              |
| ---------------------------------- | -------- | ------------------------------------------------- |
| `.ad-banner`                       | ✅       | class 选择器，匹配所有带该 class 的元素           |
| `#popup`                           | ✅       | id 选择器，匹配该 id 的元素                       |
| `div[data-ad] > a[href*="click"]`  | ✅       | CSS 选择器（属性 / 后代组合），用于没有 class/id 的元素 |
| `a[target="_blank"][href="#"]`     | ✅       | CSS 选择器（属性选择器），精确屏蔽特定标签        |
| `ad-container`                     | ❌       | 纯名称无法区分 class / id，会提示加 `.` 或 `#` 前缀，或改用 CSS 选择器 |
| `div`                              | ❌       | 纯标签名同理（要按标签屏蔽请写更明确的选择器，如 `body > div`） |
| `.foo, #bar` / `div, span`         | ❌       | 一次填多个，会提示每次只能屏蔽一个元素            |

> 每次「保存」只能添加**一个**元素：需要屏蔽多个时，重复进入二级菜单保存即可（已屏蔽的元素在网址的抽屉里管理）。
> 写入规则时，`.` / `#` 开头的写法记在 `selectors`，其它 CSS 选择器记在 `cssSelectors`，两者在页面上都会按 CSS 选择器解析。
> 为兼容旧版本数据，内容脚本仍支持不带前缀的旧写法（会同时当作 class 和 id 匹配），但弹窗中已不允许这样输入。

### 一级菜单 / 二级菜单

**一级菜单（网址列表）**：一条规则只显示一行网址，右侧依次是：

| 控件           | 作用                                          |
| -------------- | --------------------------------------------- |
| 网址（可点击） | 点击进入该网址的二级菜单（修改网址 / 追加屏蔽元素） |
| 抽屉按钮 `▸ 3` | 展开 / 收起该网址下已屏蔽的元素（数字为数量） |
| 规则开关       | 启停整条规则（规则内元素一起生效 / 失效）     |
| 🗑️             | 删除整条规则                                  |

**抽屉（已屏蔽的元素）**：点开抽屉后，该网址下所有被屏蔽的元素会**竖向排列**，每个元素一行：

- **小开关**：单独控制是否屏蔽这个元素，关闭后页面上对应元素会立即恢复显示
- **`✕`**：把该元素从屏蔽列表中移除

**二级菜单（编辑界面）**：点击网址或「+ 添加规则」进入。元素输入框始终是空的，也不会显示已经屏蔽的元素（这些元素在抽屉里管理）；填好后点「保存」：

- 新增规则时：创建一条新规则（默认启用），需要填写网址规则 + 一个屏蔽元素
- 点击已有网址进入时：**网址会回填，可以直接修改**（留空会提示「请填写网址规则」）；元素输入框填了就**追加**到该网址下（原有元素保持不变，「已经屏蔽过」的元素会自动跳过），只改网址、不填元素也能保存；两者都没改会提示「没有需要保存的修改」

输入框的校验规则（只有一个「屏蔽元素」输入框）：

| 情况                                | 规则                                                                 |
| ----------------------------------- | -------------------------------------------------------------------- |
| `.ad-banner` / `#popup`             | ✅ 允许，按 class / id 屏蔽                                           |
| `div[data-ad] > a`、`a[href="#"]`   | ✅ 允许，按完整 CSS 选择器屏蔽（用于没有 class / id 的元素）          |
| `ad-container`、`div`（纯名称）     | ❌ 拒绝，提示加 `.` / `#` 前缀，或改写为完整的 CSS 选择器             |
| `.foo, #bar`、`div, span`（多个）   | ❌ 拒绝，提示每次只能屏蔽一个元素                                     |
| `div[` 等非法写法                   | ❌ 拒绝，提示不是合法的 CSS 选择器                                    |

> 也就是说**每次保存只会添加一个元素**；需要屏蔽多个元素时，重复进入二级菜单保存即可。

### 配置导出 / 导入

一级菜单底部的 **「导出配置」** / **「导入配置」** 按钮用于备份、迁移规则：

- **导出**：把当前全部规则导出成 JSON 文件，文件名形如 `block-web-element-20260916-1630.json`
- **导入**：选择 JSON 文件即可导入，导入完成后提示「导入成功：新增 X 条，更新 Y 条」

导出的文件格式：

```json
{
  "app": "Block Web Element",
  "version": 1,
  "exportedAt": "2026-09-16T08:00:00.000Z",
  "rules": [
    {
      "id": "m1a2b3c4",
      "urlPattern": "example.com",
      "selectors": ".ad-banner, #popup",
      "cssSelectors": "div[data-ad] > a",
      "disabledTargets": ["s:.ad-banner"],
      "enabled": true
    }
  ]
}
```

导入时的规则：

| 情况                              | 行为                                                                 |
| --------------------------------- | -------------------------------------------------------------------- |
| 规则 `id` 与本地相同              | **更新**该条规则（不会新增重复项）                                   |
| 规则 `id` 不存在                  | 作为新规则**追加**                                                   |
| 文件是裸数组 `[{...}, {...}]`     | 同样支持（等价于 `{ "rules": [...] }`）                              |
| `enabled` / `disabledTargets` / `id` 缺失 | 补默认值：`true` / `[]` / 自动生成一个 id                     |
| 写的是 `url` 而不是 `urlPattern`  | 也会被识别为网址规则                                                 |
| 某条既没有网址也没有元素的条目    | 忽略该条                                                             |
| 文件不是合法 JSON、或没有任何可用规则 | 提示错误，**不会改动**现有规则                                   |

> 导入**不会删除**任何现有规则（按 `id` 合并），所以重复导入同一份文件不会产生重复规则。

## 项目结构

```
block-web-element/
├── manifest.json          # 扩展清单（Manifest V3，文案走 __MSG__）

├── popup/
│   ├── popup.html         # 弹窗界面（静态文案用 data-i18n 标记）
│   ├── popup.css          # 弹窗样式
│   └── popup.js           # 规则管理、元素开关、配置导入导出
├── _locales/
│   ├── zh_CN/messages.json # 简体中文文案（默认语言）
│   └── en/messages.json    # 英文文案
├── icons/                 # 扩展图标（16 / 48 / 128）
└── scripts/
    └── generate-icons.js  # 图标生成脚本（可选，重新生成图标用）
```

## 多语言

- 文案集中在 `_locales/<语言>/messages.json`，扩展名 / 描述 / 图标提示在 `manifest.json` 里用 `__MSG_xxx__` 引用，界面文案在 `popup.html` 里用 `data-i18n` / `data-i18n-placeholder` 标记，运行时由 `popup.js` 的 `applyI18n()` 注入
- 语言由 Chrome 的界面语言决定（`default_locale` 为 `zh_CN`）：中文环境显示中文，英文环境显示英文，找不到对应语言时回落到默认语言
- 新增语言：复制 `_locales/en` 为 `_locales/<语言代码>`（如 `ja`），翻译 `messages.json` 的 value 即可，key 不要改名

## 技术说明

- 使用 **Manifest V3** 规范
- 使用 `chrome.storage.local` 存储规则，规则修改通过 `storage.onChanged` 实时同步到所有已打开的页面
- 元素隐藏使用内联 `display: none !important` 并打上标记，避免被页面样式覆盖或重复处理
- 通过 `MutationObserver` 监听 DOM 变化，持续隐藏动态加载的目标元素
- 元素输入框同时支持 class / id 与 CSS 选择器：class / id 必须带 `.` 或 `#` 前缀，其它写法必须是合法的 CSS 选择器；每次保存只添加一个元素（弹窗会校验前缀、数量与选择器合法性）。为兼容旧数据，内容脚本仍支持不带前缀的旧写法
- 写入规则时按写法分流：`.` / `#` 开头记入 `rule.selectors`，其它 CSS 选择器记入 `rule.cssSelectors`；内容脚本对两者都用同一套选择器解析
- 规则的每个元素都有独立的开关状态，被关闭的元素记录在规则的 `disabledTargets` 字段中（形如 `s:.ad-banner`、`c:a[href]`），内容脚本在解析选择器时会跳过它们；取消屏蔽时会把元素的内联 `display` 还原为屏蔽前的值，因此开关可以随时来回切换
- 二级菜单只做「追加」：保存时把新输入的元素与已有元素去重后合并进 `rule.selectors` / `rule.cssSelectors`，不会覆盖已有元素；新加入的元素默认开启屏蔽
- 二级菜单里网址会回填并可修改，保存时直接更新该规则的 `rule.urlPattern`（改动网址不影响已屏蔽元素与各自的开关状态）
- 规则是否生效只由 `rule.enabled` 决定（二级菜单中不再提供「启用此规则」勾选框），在一级菜单的开关里切换，新增规则默认启用
- 配置导出使用 `Blob` + `<a download>` 触发下载；导入使用 `<input type="file">` + `File.text()` 读取内容，解析规范后按 `id` 合并（存在则更新、不存在则追加），最后走同一套 `chrome.storage.local` 保存与渲染流程
- 多语言基于 `chrome.i18n`：`manifest.json` 用 `__MSG__`，HTML 用 `data-i18n` / `data-i18n-placeholder` + `applyI18n()`，JS 里的文案统一走 `msg(key, subs)`；中英文 key 完全一致（有测试保证）

## 常见问题

**Q: 修改规则后已打开的页面没有生效？**
A: 正常情况下会自动生效。如果没反应，刷新一下页面即可。

**Q: 某些元素隐藏后又出现了？**
A: 如果页面 JS 动态重绘该元素（而非仅仅修改样式），需要保证新元素带有相同的 class/id —— 扩展的 MutationObserver 会自动处理这种情况。

**Q: 某个元素没有 class 也没有 id，怎么屏蔽？**
A: 直接在「屏蔽元素」输入框里填完整的 CSS 选择器，例如 `a[target="_blank"][href="#"]`、`div[data-ad] > a`，即可按标签 / 属性精确匹配并屏蔽该元素。

**Q: 为什么纯名称（如 `ad-container`、`div`）会被拒绝？**
A: 因为纯名称无法区分是 class、id 还是标签，容易误屏蔽；请写成 `.ad-container`（class）、`#ad-container`（id），或写出更明确的选择器（如 `body > div`）。旧版本里已经保存的不带前缀写法仍然可以正常生效。

**Q: 想一次屏蔽多个元素怎么办？**
A: 现在每次「保存」只能添加一个元素：重复进入二级菜单（点网址）逐个保存即可；已屏蔽的元素可以在网址的抽屉里统一开关 / 移除。

**Q: 只想屏蔽规则里的其中一部分元素？**
A: 点开该网址右侧的抽屉按钮，已屏蔽的元素会竖向列出，每个元素带一个独立开关，关掉即可单独取消该元素的屏蔽（页面上该元素会立即恢复显示），开关状态会随规则一起保存。

**Q: 怎么给某个网址再增加一个被屏蔽的元素？**
A: 点击该网址进入二级菜单（输入框是空的，也不会显示已有元素），填好后点「保存」即可追加；已经屏蔽过的元素会自动跳过，不会重复。

**Q: 怎么彻底删掉某个被屏蔽的元素？**
A: 在网址的抽屉里点该元素右侧的 `✕` 即可把它从屏蔽列表中移除；如果只是暂时不想屏蔽，用开关停用即可（页面会自动恢复显示）。

**Q: 怎么修改某个规则的网址？**
A: 点击一级菜单里的网址进入二级菜单，网址输入框已经回填当前网址，直接改掉再点「保存」即可（只改网址、不填元素也能保存；改动网址不会影响该网址下已屏蔽的元素和它们的开关状态）。

**Q: 怎么临时停用某条规则？**
A: 在扩展弹窗中点击该网址卡片上的开关即可停用整条规则；只想停用其中某个元素时，点开抽屉关掉该元素的小开关即可，两者都不需要删除规则。

**Q: 换设备 / 重装扩展后怎么迁移配置？**
A: 在旧设备点「导出配置」得到 JSON 文件，在新设备点「导入配置」选择该文件即可；同 `id` 的规则会被更新而不是重复添加。

**Q: 导入会覆盖我现有的规则吗？**
A: 不会删除任何现有规则：导入的规则若 `id` 与本地相同就更新该条，其余作为新规则追加。导入后会提示「新增 X 条，更新 Y 条」，方便确认结果。

**Q: 界面语言怎么切换？**
A: 跟随 Chrome 的界面语言自动切换（内置简体中文 `zh_CN` 与英文 `en`）；想支持别的语言，复制 `_locales/en/messages.json` 到对应语言目录（如 `_locales/ja/messages.json`）并翻译 value 即可，key 保持不变。

**Q: 可以手动写配置文件再导入吗？**
A: 可以。文件可以是导出时的完整格式，也可以是裸数组 `[{ "urlPattern": "example.com", "selectors": ".ad-banner" }]`；`enabled`、`disabledTargets`、`id` 都可以省略（分别默认 `true`、`[]`、自动生成），`url` 与 `urlPattern` 等价。
